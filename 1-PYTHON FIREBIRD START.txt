Tu počinje Python aplikacija.

1. Instalirati Firebird 3.0 pa ga deinstalirati
   (On ostavi neke postavke koje trebaju)
2. Instalirati Firebird 1.5.6.
3. u SysWOW64 kopirati fbclient.dll Firebirda 3.0 veličine 1.299 KB

4. Instalirati Python 3.12   32-bitni
5. U VSCode instalirati Python languagge support (Microsoft)
6. Instalirati Python packages

   pip install flask 
   pip install fdb tkcalendar pyinstaller

// nadogradnja pip-a
python -m pip install --upgrade pip
